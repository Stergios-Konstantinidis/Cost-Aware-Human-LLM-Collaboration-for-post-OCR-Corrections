# Results Directory

All experimental outputs, organized by category.  
Large JSON data files are `.gitignore`d; figures and logs are tracked.

---

## `baselines/` — Raw OCR Baselines

Per-document WER/CER for each OCR engine **without** any LLM correction.

| File | Description |
|------|-------------|
| `baseline_tesseract.json` | Tesseract baseline metrics (~632 documents) |
| `baseline_easyocr.json` | EasyOCR baseline metrics |
| `baseline_paddle.json` | PaddleOCR baseline metrics |

## `corrections/` — LLM Correction Outputs

Per-document correction results from the evaluation pipeline, organized by OCR engine.

```
corrections/
├── tesseract/   423 files — e.g. tesseract_Full_Advanced_5_google__gemini-3-flash-preview.json
├── easyocr/     373 files — e.g. easyocr_Selective_thr80_Basic_1_openai__gpt-4o-mini.json
└── paddle/       50 files — e.g. paddle_ConditionalFull_thr90_10_meta-llama__llama-3.3-70b-instruct.json
```

**Naming convention:** `{engine}_{Strategy}_{PromptLevel}_{PromptID}_{LLMModel}.json`

Each JSON is an array of per-document records:
```json
[{"filename": "img_001.png", "groundtruth": "...", "raw_ocr": "...", "corrected_ocr": "...", "wer": 0.12, "cer": 0.04, "cost": 0.001}, ...]
```

## `ml_models/` — Trained Model Results

Classifier and regression experiment outputs.

| File | Description |
|------|-------------|
| `gbt_classifier_results.json` | GBT binary classifier — LOO results, per-threshold metrics, feature importances |
| `svm_classifier_results.json` | SVM classifier variant |
| `linear_regression_results.json` | Ridge regression (per-engine) — predicted vs. actual WER/CER |
| `linear_regression_pooled_noemb_results.json` | Ridge regression (pooled, no embeddings) |
| `nn_regression_results.json` | MLP regression (per-engine) |
| `nn_regression_pooled_noemb_results.json` | MLP regression (pooled, no embeddings) |
| `predictions_ridge_noemb.json` | Per-document Ridge predictions (used by routing analysis) |
| `predictions_nn_noemb.json` | Per-document MLP predictions (used by routing analysis) |
| `confbert_probas.npy` | ConfBERT routing probabilities (NumPy array, 597 values) |

## `routing/` — Routing Analysis Data

Threshold sweep and routing table used for cost–quality frontier analysis.

| File | Description |
|------|-------------|
| `routing_table.json` | Full per-document routing table with predictions and corrections |
| `routing_threshold_sweep.json` | Threshold sweep summary — one row per threshold × model |
| `regression_routing_results.json` | Regression-based routing experiment results |

## `confidence_data/` — OCR Confidence Scores

Per-document and per-line OCR confidence data used for selective correction.

| File | Description |
|------|-------------|
| `word_confidences_tesseract.json` | Per-word Tesseract confidence scores |
| `low_confidence_words_{thr}_{engine}.json` | Lines below threshold `thr` (e.g., 80, 90) per engine — includes `avg_confidence` per document |

## `summaries/` — Aggregated Results

High-level summaries across all experiments.

| File | Description |
|------|-------------|
| `summary.json` | Full summary — grouped by (strategy, LLM model) with per-engine WER/CER |
| `summary_conditional.json` | ConditionalFull strategy summary |
| `leaderboard.json` | Ranked leaderboard sorted by overall WER |
| `ortho_summary.json` | Orthographic (spell-check) correction results at various thresholds |

## `figures/` — Generated Visualizations

All plots generated by `code/plotting/` scripts.

```
figures/

├── routing_graph_guarded.png        ← With overcorrection guard
├── routing_density.png              ← Routing decision distribution
├── threshold_comparison.png         ← Threshold sweep overlay
├── correction_strategies_comparison.png
├── routing_frontier/                ← 36 PNGs — routing frontiers at varying δ (Tesseract + Paddle)

└── confidence/                      ← 4 PNGs — confidence distributions, error vs. confidence
```

## `threshold_sweep/` — Threshold Sweep Graphs

31 PNG files — one routing graph per min-delta threshold value.

Naming: `routing_x_{neg|pos}{value}.png` (e.g., `routing_x_neg0.050.png`, `routing_x_pos0.100.png`)
